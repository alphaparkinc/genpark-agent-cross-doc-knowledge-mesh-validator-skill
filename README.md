# genpark-agent-cross-doc-knowledge-mesh-validator-skill

Multi-document enterprise knowledge mesh synthesizer detecting contradictions, outdated spec clauses, and missing dependencies across PRDs, RFCs, and wikis.

## Architecture
- **Input**: Set of technical markdown, docx, or RFC text files.
- **Engine**: Invariant comparison and cross-document discrepancy analyzer.
- **Output**: Structured conflict report and reconciliation roadmap.
